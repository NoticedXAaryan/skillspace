## Vercel Environment Variables (Copy-Paste Ready)

Go to: **Vercel Dashboard → skillspace-registry → Settings → Environment Variables**

Add these (select "Production" scope):

### Required

| Name | Value | How to get |
|------|-------|-----------|
| `DATABASE_URL` | `postgresql://neondb_owner:xxx@ep-xxx.us-east-2.aws.neon.tech/skillspace?sslmode=require` | Neon Console → Connection Details → Pooled connection → Copy |
| `BETTER_AUTH_SECRET` | Run `openssl rand -base64 32` in terminal, paste output | Generate a random secret |
| `BETTER_AUTH_URL` | `https://skillspace-registry.vercel.app` | Your Vercel domain |
| `NEXT_PUBLIC_APP_URL` | `https://skillspace-registry.vercel.app` | Your Vercel domain |

### Optional (GitHub Sign-In)

| Name | Value | How to get |
|------|-------|-----------|
| `GITHUB_CLIENT_ID` | `Iv1.xxxxx` | GitHub → Settings → Developer Settings → OAuth Apps → New OAuth App. Set Homepage URL to your domain, Callback URL to `https://skillspace-registry.vercel.app/api/auth/callback/github` |
| `GITHUB_CLIENT_SECRET` | `xxxxx` | Same page → Generate a new client secret |

### Optional (File Storage)

| Name | Value | How to get |
|------|-------|-----------|
| `STORAGE_BUCKET` | `skillspace-packages` | Cloudflare R2 → Create bucket |
| `STORAGE_ENDPOINT` | `https://xxx.r2.cloudflarestorage.com` | R2 → Settings → S3 API |
| `STORAGE_ACCESS_KEY` | `xxx` | R2 → Manage R2 API Tokens → Create API Token |
| `STORAGE_SECRET_KEY` | `xxx` | Same token creation |

After adding all vars → **Redeploy** the project.
